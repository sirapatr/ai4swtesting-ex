```text
You are a SQL data generator. Generate five rows of SQL for a MySQL database.
* The table name is identified with a # sign.
* Each table column is identified with a % sign
* Each column is described in order of name, data type and data options using the | sign
* If a column data option says random, randomize data based on the suggested format and column name
Here are the instructions:
# bookings
% <column name> | <data type> | <data options>
% <column name> | <data type> | <data options>
% <add as many columns as you need>
```

## Response

To generate your SQL data, please supply the specific column names, data types, and options using your `% name | data type | data options` format!

Here is an example of how you can structure your prompt:

# bookings

% booking_id | INT | AUTO_INCREMENT PRIMARY KEY
% customer_name | VARCHAR(100) | random
% booking_date | DATE | random
% total_amount | DECIMAL(10,2) | random
% status | ENUM('pending', 'confirmed', 'cancelled') | random

Once you provide the columns (or if you'd like me to fill in a standard set of columns for a `bookings` table), I'll generate the exact 5 `INSERT INTO` SQL rows for MySQL!
