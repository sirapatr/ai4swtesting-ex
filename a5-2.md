# Activity 5 – Step 2: With examples (few-shot)

**Chatbot / model:** ChatGPT (GPT-5)

## Prompt

```text
You are a software tester. Write 6 test ideas for the password rules delimited by three hashes. Use our team's test idea format.
###
A password must be 8 to 20 characters long and contain at least one digit and one uppercase letter.
###
For example:
* [BVA] 7 characters, one below the minimum ("Secret1") → rejected
* [EP] no digit ("SecretPass") → rejected
```

## Response

1. [BVA] 7 characters, one below the minimum (`Secret1`) → rejected
2. [BVA] 8 characters, minimum valid length (`Secret1A`) → accepted
3. [BVA] 20 characters, maximum valid length (`SecretPassword1234A`) → accepted
4. [BVA] 21 characters, one above the maximum (`SecretPassword12345A`) → rejected
5. [EP] No digit (`SecretPass`) → rejected
6. [EP] No uppercase letter (`secret123`) → rejected
